# 第十四夜 永不靠岸的游轮

基于《第十四夜》V1.1 的浏览器调查试玩。包含7个舱室、4名关键NPC、时间循环、证据推理、密码柜、配电谜题、保存者授权、3种结局及中转站记忆回收。

## 在线试玩

GitHub Pages：https://Katieliu123456.github.io/fourteenth-night/

源码仓库：https://github.com/Katieliu123456/fourteenth-night

## 开始试玩

在本文件所在目录运行：

```sh
npm start
```

浏览器打开 `http://127.0.0.1:4173`。若4173端口被占用，可运行 `PORT=4174 node server.cjs`。

也可以直接打开 `dist/index.html`；所有画面、字体回退与逻辑均不依赖外部服务。部分浏览器限制本地文件存档，建议使用本机服务。

## 操作

- 选择男女主角，登船后点击场景数字标记或物品卡。
- 沿地图相邻路线移动，每次消耗1分钟。时间按行动推进；阅读、对话和谜题不走时。
- “等待”跳到指定事件时间。00:14自动重置；客舱怀表可主动重置。
- 线索、已证实推论与经验保留；钥匙、继电器、配电、路易协助及保存者授权在每轮复位。
- 证据板选中2～3份记录后验证。错误连接没有惩罚。
- 最终决定先展示明确人数后果，再要求玩家确认。
- 存档只写入当前浏览器的本地存储，不上传个人数据。清除网站数据会删除存档。

## 实现边界

这是一套完成调查闭环的平面互动原型，尚不包含正式3D、自由行走、配音、战斗、其余13世界及完整角色升级树。性别选择在本版记录于存档与状态显示，尚无不同角色建模。时间采用行动推进，便于验证调查路线；正式版本可替换时钟适配层。

三个世界结局与简短中转站已实现。人格系统先记录具体行为与理由，未实施完整14世界的终局质询。没有使用生成式AI接口或付费API。

## 工程结构

- `dist/data.js`：舱室、线索、推论与结局内容。
- `dist/engine.js`：独立规则状态机，可继续复用于其他世界。
- `dist/app.js`：交互、界面、本地存档。
- `dist/art.js`：原创SVG场景。
- `dist/style.css`：响应式界面与减少动态效果支持。
- `tests/engine.test.cjs`：主线可达性、三结局、循环、防刷经验、存档及失败恢复检查。
- `docs/plans/2026-10-28-cruise-prototype.md`：本次实施范围。

运行 `npm test` 验证逻辑。本项目无第三方运行依赖，推荐Node.js 20或更新版本。

## 试玩参考路线 含剧透

1. 客舱取证：乘船证与服务手册。
2. 酒吧询问艾琳，查看名册、路易运送单、钢琴谱。谱子可交还艾琳。
3. 甲板核实救生艇、调查维修侧门；留在甲板等待00:09，留下行程影像。
4. 进入驾驶室，查看监控、门禁日志、旧授权，质询船长取得通行证。
5. 证据板：运送单＋门禁日志；监控＋门禁日志＋甲板行程。
6. 回客舱重置，在新一轮等待00:03，再进入医务室。询问医生、查看值班记录和病历。柜码1104。
7. 证据板：237人名册＋14人保存病历。
8. 机舱取继电器、检查桥接技术卡。配电设为控制2、保存3、照明1。
9. 进入保存舱查看登船票。若追求救援结局，在已核实艇位与转移方案后取得14份知情授权。
10. 核心选择任一已满足条件的方案，阅读后果并确认。完成后可返回中转站或继续探索其他结局。

下一步建议验证首玩者是否能自己找到甲板行程与三组证据关联，再扩展实时循环、自由移动和下一世界。
