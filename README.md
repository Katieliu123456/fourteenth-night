# 第十四夜 · 永不靠岸的游轮

第三人称浏览器悬疑调查试玩 v0.3：7 个可行走舱室、7 名 NPC、分支对话、14 分钟循环、证据推理与 3 种结局。画面采用原创的低饱和纸张、墨线和超现实绘本风格。

[在线试玩](https://katieliu123456.github.io/fourteenth-night/) · [源码](https://github.com/Katieliu123456/fourteenth-night)

## 本版更新

- 可见男女主角全身：复古长外套、衬衫、皮靴、便帽与皮革背包；行走有肢体动作。镜头跟随主角，支持环绕，并在舱壁与家具前收回。
- 原有艾琳、林医生、船长和路易加入分支对话；新增领班秦雾、护理员苏禾、信号员纪川。对话提供原创绘本肖像、明确选项、关系反馈与已选状态。
- 选择会改变实际规则。例如坦白失忆获得医务室通行条，假装恢复身份获得驾驶室引见；之前说过的话会改变纪川要求的证据。争取船长或信号员协助可提供另一条配电路线；让路易撤离后，他不再协助配电。
- 路易提供的维护纸带可与录像、门禁日志组成另一组身份推论证据，减少错过 00:09 甲板事件后的等待。
- 本轮的承诺有约束，不能立刻改选；循环重置会收回临时通行和协助，关系、选择记录与获得的知识保留。结局回应会提及本次交流产生的结果。
- 原创程序化环境音乐，以及木地板、地毯、金属、瓷砖/石板四类脚步音效。脚步根据实际移动距离和材质触发，停步、顶墙、阅读和暂停时不会继续播放脚步。工具栏“声音”可静音、分别调节音乐/脚步，或试听材质。

## 开始试玩

在项目目录运行 `npm start`，打开 `http://127.0.0.1:4173`。端口占用时可运行 `PORT=4175 node server.cjs`。

运行时无需安装依赖或外部 CDN；Three.js 已随文件提供。3D 页面需要 WebGL 2，请通过本机服务或在线试玩打开。

- 标题页选择“第三人称探索”，登船后点击“开始自由探索”。WASD 移动，Shift 加快，拖动画面或方向键环绕查看。
- 走近人物、物品和舱门，朝向目标按 E。地图帮助辨认方向，不提供传送。手机可用方向按钮行走、拖动查看。
- B 证据板，M 地图，N 档案，F 手电筒，Esc 暂停。暂停菜单可切换平面调查。
- 行走、阅读与思考不走时；通过舱门推进 1 分钟。等待可跳到事件时刻，00:14 自动重置。
- 线索、经验与推论跨循环保留；实物、配电与知情授权在每轮重新获取。错误证据与错误配电不会永久锁死主线。
- 旧版存档自动补齐新增字段，保留调查进度；存档仅保存在当前浏览器，不上传个人数据。刷新后从标题页继续夜航。
- 声音在首次点击开始探索或试听后启动；浏览器静音会影响播放。音乐与脚步音量偏好单独保存。

## 试玩参考路线（含剧透）

1. 在客舱取乘船证和服务手册，去酒吧听艾琳的经历，查看名册、运送单与钢琴谱；把谱子交还她。
2. 与秦雾交谈，决定坦白失忆还是维持旧身份。前往医务室听林医生的解释、查值班板与病历；备用柜密码 1104。
3. 在甲板调查艇位和维修侧门。可等待 00:09 留下行程影像，也可稍后救下路易，取得维护纸带。
4. 在驾驶室调查录像、门禁日志和旧授权，向船长说明调查结果。推论：运送单＋日志；录像＋日志＋行程影像（或维护纸带）；名册＋病历。
5. 进入机舱查看桥接技术卡，取继电器或争取协助。配电设为控制 2、保存 3、照明 1。若路易撤离，须使用继电器或其他 NPC 协助。
6. 核实艇位与转移方法后，可向纪川完整说明风险，争取广播协助。与苏禾建立联络后可远程征求知情授权；原保存舱授权终端依然可用。
7. 进入保存舱取得票据，完成本轮知情授权，选择结局；最终确认前可阅读具体人数后果。三条结局均保留。

## 工程与验证

- `dist/data.js` / `stories.js`：世界内容、NPC 对话、分支条件与后果。
- `dist/engine.js`：纯规则状态机、存档兼容、推理与结局。
- `dist/navigation.js` / `world3d.js`：碰撞、材质、门、近距离交互与第三人称镜头。
- `dist/actors.js` / `illustration.js`：原创程序化人物、纹理与肖像。
- `dist/audio.js`：合成音效、距离步频、音乐与音量保存。
- `dist/app.js` / `conversations.js` / `ui3d.js`：调查、对话、声音设置与 HUD。
- `tests/`：运行 `npm test`；38 项检查覆盖原主线和三结局、所有入口与物品可达、对话后果、防刷奖励、旧存档、材质脚步波形和镜头边界。
- `docs/verification.md`：实际浏览器检查范围与限制。

这是风格化可玩原型。NPC 使用程序化模型与文字对话，尚无正式配音、口型和精细人物动画；舱门使用场景过渡，其余 13 个世界尚未开发。关系系统目前作用于游轮篇，未实现 14 世界终局人格质询。尚未以真实低端手机验证性能。

## 更新 GitHub Pages

修改 `dist/` 后运行 `npm test` 和 `npm run prepare:pages`，将源码和生成的 `docs/` 同时提交到 `main`。Pages 使用 `main` 的 `/docs` 目录；资源路径均为相对路径。

Node.js 20 或更新版本可运行检查。Three.js 固定 0.186.1，仅更新引擎时需要 `npm ci` 后执行 `npm run vendor:3d`。
