# 第十四夜 永不靠岸的游轮

基于《第十四夜》V1.1 的第一人称 3D 浏览器调查试玩 v0.2。包含7个舱室、4名关键NPC、时间循环、证据推理、密码柜、配电谜题、保存者授权、3种结局及中转站记忆回收。

## 在线试玩

GitHub Pages：https://Katieliu123456.github.io/fourteenth-night/

源码仓库：https://github.com/Katieliu123456/fourteenth-night

## 开始试玩

在本文件所在目录运行：

```sh
npm start
```

浏览器打开 `http://127.0.0.1:4173`。若4173端口被占用，可运行 `PORT=4174 node server.cjs`。

3D 版使用 ES 模块，请通过上述本机服务或 GitHub Pages 打开。Three.js 已随游戏文件提供，运行时不依赖 CDN；浏览器需要支持 WebGL 2。

## 3D 自由探索

标题页选择“3D 自由行走”，登船后点击“开始自由探索”。

- WASD 行走，Shift 加快；拖动画面转向，或使用左右方向键。
- 走近物品、人物或实体舱门，面向目标按 E。地图用于辨认方向，不能传送。
- B 证据板，M 舱室图，N 档案，F 手电筒，Esc 暂停。可选择鼠标随视角，也可直接拖动查看。
- 手机使用方向按钮行走，在画面中拖动查看。
- 行走与阅读不消耗时间；通过舱门推进1分钟。七个舱室之间使用短暂画面过渡。
- 阅读对话、打开证据板、暂停、切换标签页都会停止移动。
- 调查存档与 v0.1 共用；3D 位置另行保存。刷新后可从当前舱室与位置继续。
- 保留平面调查模式；设备无法启动 WebGL 时会回到平面版。

## 原有调查操作

- 选择男女主角，登船后点击场景数字标记或物品卡。
- 沿地图相邻路线移动，每次消耗1分钟。时间按行动推进；阅读、对话和谜题不走时。
- “等待”跳到指定事件时间。00:14自动重置；客舱怀表可主动重置。
- 线索、已证实推论与经验保留；钥匙、继电器、配电、路易协助及保存者授权在每轮复位。
- 证据板选中2～3份记录后验证。错误连接没有惩罚。
- 最终决定先展示明确人数后果，再要求玩家确认。
- 存档只写入当前浏览器的本地存储，不上传个人数据。清除网站数据会删除存档。

## 实现边界

这是一套完成游轮调查闭环的风格化 3D 可玩原型：七个可行走舱室、原创程序化环境、四名风格化 NPC、船体与主要家具碰撞、近距离调查、存档与三结局。舱门切换不是无缝整船。尚不包含正式人物动作与口型、配音、战斗、其余13世界及完整角色升级树。男女主均使用第一人称，性别记录于剧情存档；没有可见的主角全身模型。时间仍按行动推进。

三个世界结局与简短中转站已实现。人格系统先记录具体行为与理由，未实施完整14世界的终局质询。没有使用生成式AI接口或付费API。

## 工程结构

- `dist/data.js`：舱室、线索、推论与结局内容。
- `dist/engine.js`：独立规则状态机，可继续复用于其他世界。
- `dist/app.js`：交互、界面、本地存档。
- `dist/art.js`：原创SVG场景。
- `dist/style.css`：平面调查界面。
- `dist/navigation.js`：七舱布局、碰撞、门与可交互范围。
- `dist/world3d.js`：Three.js 场景、人物、第一人称输入与位置存档。
- `dist/ui3d.js` / `dist/walk3d.css`：3D HUD、暂停与地图。
- `tests/navigation.test.cjs`：每个入口的安全位置、所有物品可达、墙体防穿透与交互距离。
- `tests/engine.test.cjs`：主线可达性、三结局、循环、防刷经验、存档及失败恢复检查。
- `docs/plans/2026-10-28-cruise-prototype.md`：本次实施范围。

运行 `npm test` 验证逻辑。推荐 Node.js 20 或更新版本。页面随附固定版本 Three.js 0.186.1；仅更新引擎时需要 `npm ci` 后执行 `npm run vendor:3d`。

## 试玩参考路线 含剧透

1. 客舱取证：乘船证与服务手册。
2. 酒吧询问艾琳，查看名册、路易运送单、钢琴谱。谱子可交还艾琳。
3. 甲板核实救生艇、调查维修侧门；留在甲板等待00:09，留下行程影像。
4. 进入驾驶室，查看监控、门禁日志、旧授权，质询船长取得通行证。
5. 证据板：运送单＋门禁日志；监控＋门禁日志＋甲板行程。
6. 回客舱重置，在新一轮等待00:03，再进入医务室。询问医生、查看值班记录和病历。柜码1104。
7. 证据板：237人名册＋14人保存病历。
8. 机舱取继电器、检查桥接技术卡。配电设为控制2、保存3、照明1。
9. 进入保存舱查看登船票。若追求救援结局，在已核实艇位与转移方案后取得14份知情授权。
10. 核心选择任一已满足条件的方案，阅读后果并确认。完成后可返回中转站或继续探索其他结局。

下一步建议验证首玩者是否能自己找到甲板行程与三组证据关联，再完善人物动作、声音与场景细节。
