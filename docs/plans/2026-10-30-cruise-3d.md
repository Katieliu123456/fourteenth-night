# Cruise First-Person 3D Implementation Plan

**Goal:** Turn the complete first world into seven freely walkable, furnished 3D interiors with nearby interaction and physical doorway transitions, preserving all evidence, puzzles and three endings.

**Architecture:** Reuse the tested story engine. A separate Three.js renderer owns camera, furniture, collision, local position and proximity. DOM dialogs own investigation and choices. Pausing, reading and changing tabs stop movement. The 2D version remains available and shares the story save.

**Tech Stack:** Pinned Three.js 0.186.1, ES modules, native JavaScript, procedural original geometry and textures, Node test runner, GitHub Pages static hosting.

## Implementation
1. Add a shared navigation layout for all seven rooms. Test obstacles, sliding, large movement steps, reachable object approach points, door access and game gates.
2. Create original room geometry, furniture, four stylized characters, lighting, water and interaction markers. No remote media or runtime CDN.
3. Add first-person movement, drag/mouse look, optional pointer lock, touch controls, collision and nearby E interaction. Doorways connect rooms with a short transition, not a seamless ship exterior.
4. Connect 3D HUD, map, evidence board, dialogs, loop reset and saves. Prevent camera movement while dialogs, pause or page hiding are active. Retain readable 2D fallback when WebGL is unavailable.
5. Test story rules and navigation, verify actual browser rendering, movement, investigation, doors and reload. Sync all static assets to Pages, publish the existing repository and verify the deployment.

## Experience decisions
- User confirmed first-person investigation.
- Existing action-based clock retained: crossing a doorway advances one minute; walking and reading do not consume time.
- Art direction: midnight teal, brass, dark timber, worn red carpeting, warm lamps; stylized environmental models and characters.
- This stage does not add third-person character animation, combat, real-time scheduling or the other thirteen worlds.
